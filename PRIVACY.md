# Privacy Policy

**Click Define** does not collect, store, or transmit any personal information.

## Data sent to third parties

When you double-click a word, the extension sends only that single word to one or more of the following public APIs to retrieve its definition:

- **Wiktionary** (`en.wiktionary.org`) - definitions in any language, plus IPA and pronunciation audio
- **Free Dictionary API** (`api.dictionaryapi.dev`) - English pronunciation and contextual synonyms and antonyms
- **Datamuse** (`api.datamuse.com`) - synonyms and antonyms

Playing a pronunciation clip loads the audio file from Wikimedia's media host (`upload.wikimedia.org`), which `en.wiktionary.org` redirects to.

No other content from the page is transmitted. No browsing history, page content, URLs, identifiers, or user data is collected.

## What is stored locally

The extension uses Firefox's `storage.sync` API to save your settings (toggles, preferred display language). Settings are stored on your Firefox account if sync is enabled, otherwise locally. Nothing is sent to the extension author.
